# 北京进京证避让路线 — 全市静态验证页（非官方）

这是一个**免费、可在手机 Safari 打开的静态算路页**。路网覆盖 OpenStreetMap Geofabrik **北京提取全市范围**（不是六环裁切，也不是全中国）。硬排除只启用**六环内进京证相关点**（含兼拍早晚高峰与 typo）；六环外进京证与仅早晚高峰已关闭；六环字段缺失或异常不臆造为六环内，仅作风险。

**不是**官方应用，**不保证**避开抓拍或免于处罚。页面含筛选后的派生点位（按未确认的坐标假设叠加），任何有链接的人都可以打开。未上传原始全市 OSM PBF，也未上传原始摄像头 JSON。

## 打开

用 iPhone Safari 打开本仓库的 GitHub Pages 地址。无需安装 App。首次加载需下载约十几 MB 压缩路网与地点索引，请在较稳定的网络下打开；算路在手机后台线程进行。

## 可检验示例（须点选确切 OSM 编号，不要只搜同名）

- 成功蓝线：起点「东直门」`n5200295052`（片区，116.42809, 39.938659）→ 终点「月坛南街」`w1011189564`（道路，116.343192, 39.91258）。
- 合法拒绝、无蓝线：「月坛南街」`w1011189563`（116.349029, 39.912517）为终点时返回 `end_in_exclusion`；「官园桥」`n331880663` 为起点时返回 `start_in_exclusion`。这是排除规则，**没有**把排除段端点挪开凑结果。
- 公开地名「北七佳园」`w679672532`、「龙德广场」`r16672016` / `w1104052487` 可检索且在全市范围内。其质心距最近机动车道约 101 米与 123 米，会吸附到最近道路并写明距离，不改写坐标、不改选其他同名点。在上述吸附点上当前无有向通路，规划返回 `no_path`，请在地图上另点附近可通行道路。

检索「春秀路小区」时，OSM 仅有公交站台/站区域，没有住宅小区要素；结果用中文类别标明，不能当作小区入口。

## 范围、筛选与数据量

- 路网提取大约 115.40–117.53°E，39.43–41.07°N；可路由路段 287,299。
- 硬排除 5,559 个六环内进京证点（拍进京证 5,196，兼拍 362，typo 1）；关闭六环外进京证 1,113；六环字段缺失/异常 7 个仅作风险；仅早晚高峰 327 个未启用。
- 静态压缩包大约：路网 `network.json.gz` 10.4 MiB，地点索引 `places.json.gz` 3.6 MiB，主要道路底图 `roads.geojson.gz` 1.3 MiB。底图为主要道路以便手机加载；算路仍使用含支路的全市路网。
- 地点搜索仅含已命名 OSM 要素，**不保证所有小区**。面状地点用质心；超过 60 米时吸附到 250 米内最近机动车道并说明距离，不把质心改写成入口。排除区内端点仍拒绝。
- 未向在线地理编码发送查询。输入的文字本身不是坐标，须点选候选或在地图上选点。
- 已吸附点按沿路双向 100 米排除（工程假设，不是官方拍摄距离）。附近歧义或未匹配点会在结果中标明，**不能当作已经避开**。
- 坐标系：OSM 路网为 WGS84；摄像头点位按未确认的 GCJ-02→WGS84 假设转换。该假设未经官方确认。
- 转向限制：仅实现了可在本图正确执行的部分；条件限制等未作为全时规则静默套用。

页面底部用小字标明当前筛选与数据量，没有顶部大横幅。

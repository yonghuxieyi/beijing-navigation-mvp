# 北京进京证避让路线 — 局部验证页（非官方）

这是一个**局部、免费、可在手机浏览器打开的验证页面**，用于在验证范围内输入或点选起终点、做真实本地算路，并与自己的走法比对。

**不是**完整北京导航，**不是**官方应用，**不保证**避开抓拍或免于处罚。页面含验证范围内的进京证相关摄像头点位（按未确认的坐标假设叠加），任何有链接的人都可以打开。

## 打开

发布启用后，用 iPhone Safari 打开仓库 GitHub Pages 地址（见仓库 About / Pages）。无需安装 App。

## 范围与数据

- 路网与规划范围：西直门—东直门—复兴门一带验证框，不是全北京。
- 地点搜索：仅含本图已命名的 OpenStreetMap 要素（范围内全部，以及部分范围外名称用于提示“超范围、不能规划”）。**不保证所有小区**都能搜到。
- 未向在线地理编码发送查询。输入的文字本身不是坐标，须点选候选或在地图上选点。
- 已吸附到关联道路的点按沿路双向 100 米排除（工程假设，不是官方拍摄距离）。附近歧义或未匹配点会在结果中标明，**不能当作已经避开**。
- 坐标系：OSM 路网为 WGS84；摄像头点位按未确认的 GCJ-02→WGS84 假设转换。该假设未经官方确认。
- 转向限制：仅实现了可在本图正确执行的部分；条件限制等未作为全时规则静默套用。
